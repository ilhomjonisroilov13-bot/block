SO'Z QALQONI - Android ilovasi
================================

Nima qiladi
-----------
- Ro'yxatdan o'tish va parol bilan kirish (o'zbek tilida).
- O'zingiz so'z va ismlar ro'yxatini tuzasiz (eng ko'pi 100 ta).
- Chrome, YouTube, Google va boshqa ilovalarda shu so'z yozilsa, avtomatik
  ogohlantirish oynasi chiqadi va yozilgan matn tozalanadi.
- Ogohlantirishdagi tugmalar 3 soniyadan keyin bosiladi: bu to'xtab o'ylash uchun.
- Bugun va jami nechta urinish to'xtatilgani panelda ko'rinadi.

APK yig'ish (2 yo'l)
--------------------
1) Android Studio orqali (kompyuterda):
   - Android Studio'ni oching: File > Open > "SozQalqoniAndroid" papkasi.
   - Gradle sinxronlanishini kuting.
   - Build > Build Bundle(s) / APK(s) > Build APK(s).
   - APK: app/build/outputs/apk/debug/app-debug.apk

2) GitHub orqali (Android Studio'siz):
   - github.com'da yangi repozitoriya oching va shu papkadagi hamma fayllarni
     (".github" papkasi bilan) yuklang.
   - "Actions" bo'limida "APK yig'ish" ishga tushadi (5-10 daqiqa).
   - Tugagach, "SozQalqoni-apk" faylini yuklab oling (ichida app-debug.apk).

O'rnatish va yoqish
-------------------
1. app-debug.apk ni telefonga o'rnating ("noma'lum manbalardan o'rnatish"ga ruxsat bering).
2. Ilovani oching va ro'yxatdan o'ting.
3. "Himoyani yoqish" tugmasi > "So'z Qalqoni" ni toping > yoqing.
   Android 13 va undan yuqorida yoqib bo'lmasa:
   Sozlamalar > Ilovalar > So'z Qalqoni > yuqori o'ngdagi uch nuqta >
   "Cheklangan sozlamalarga ruxsat berish", so'ng qayta urinib ko'ring.
4. So'zlarni qo'shing va Chrome'da shu so'zni yozib sinab ko'ring.

Eslatma
-------
- Parolni unutsangiz tiklab bo'lmaydi.
- Ilovani yoki xizmatni telefon sozlamalaridan o'chirib qo'yish mumkin. Qo'shimcha
  himoya uchun Private DNS: family.cloudflare-dns.com ham yoqib qo'ying.
- Birinchi yig'ishda xato chiqsa, xato matnini yuboring: tuzatib beraman.
